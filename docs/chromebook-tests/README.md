# Chromebook用 テストプログラム1～5

公開版 https://playa2021git.github.io/block2script/ で使う作品です。公開版の全9拡張を5本に分けています。Camera Selectorは公開版対象外です。

## 共通手順

1. このフォルダーの `index.html` のリンクから各sb3をChromebookにダウンロードする。
2. 公開版の「.sb3を開く」でファイルを選ぶ。拡張は作品から自動で追加される。
3. 「パネルを隠す」でステージを広くする。ステージ内をクリックしてから、緑の旗／指定キーを操作する。Scriptの入力欄にカーソルがあるとキー操作が作品へ届かない場合がある。
4. カメラ・マイクは必要な場面で許可する。モデルの初回取得は30～60秒を目安に待つ。進まなければ授業前診断と学校の通信・権限設定を確認する。
5. 各番号は別の新しいタブで試す。終了は赤い停止ボタンを押してタブを閉じる。拡張のカメラ／音声処理は停止ボタンだけで終了しない場合がある。
6. 結果は下表へ記入。読込成功だけでは実行合格にしない。「拡張を含むsb3」はブロックと拡張IDを保存した作品で、モデル・認識サービス・機器・権限・学習データを内蔵するものではない。

## 1：基本動作・標準拡張

拡張：ペン・音楽・音声合成・翻訳。

- 緑の旗：四角形が描かれ、ピアノの音が鳴ればペンと音楽は合格。
- S：日本語で「こんにちは。クロームブックのテストです。」が聞こえれば音声合成は合格。
- T：「翻訳結果」に hello の日本語訳（例：こんにちは）が出れば翻訳は合格。
- 音が聞こえない場合は端末音量・出力先を確認する。翻訳と音声合成は外部サービスへの接続も必要。

## 2：音声認識

拡張：Speech2Scratch。マイクとブラウザの音声認識サービスを使用。

- 緑の旗を押し、Rで認識開始。マイクを許可して「こんにちは」と話す。
- 「認識した言葉」に発話内容が表示されれば合格。「マイク音量」が変化するかも確認する。
- 音量が変わるのに認識しない場合は、Speech2Scratchの通信・音声認識サービス・ブラウザ設定を切り分ける。音量計だけでは認識合格にならない。

## 3：画像学習

拡張：ML2Scratch。カメラとMobileNetのモデル取得を使用。

- 緑の旗で学習をリセットし、カメラを開始。映像とモデルの準備を待つ。
- 物Aを映して1を数回押し、「ラベル1枚数」が増えることを確認。
- 異なる物Bを映して2を数回押し、「ラベル2枚数」が増えることを確認。
- Cで分類開始。A/Bを交互に映し、「画像ラベル」が1/2に変われば合格。
- キーを連打せず、1回ずつ押す。学習枚数が増えない場合はモデル準備を待つ。初期学習データは含めていないため、開くたびにこの学習を行う。

## 4：姿勢認識とTM画像・音声

拡張：PoseNet2Scratch・TM2Scratch。

- 緑の旗のあとP：カメラを許可して顔・上半身を映す。「人数」が1以上になり、顔を動かすと「鼻X」「鼻Y」が変われば姿勢認識は合格。
- I：TM画像モデルを読み込む。手のグー・チョキ・パーを順に映し、「TM画像ラベル」が対応して変われば合格。
- A：TM音声モデルを読み込み、マイクを許可する。拍手／口笛で「TM音声ラベル」に clap／whistle が表示されれば合格。静かな状態は背景音扱いになる。
- 同じ作品の3機能は順に試す。処理が重い場合はタブを開き直して各キーを1種類ずつ試す。どの機能が通ったかを別々に記録する。
- 既定モデルURLは画像 `https://teachablemachine.withgoogle.com/models/0rX_3hoH/`、音声 `https://teachablemachine.withgoogle.com/models/xP0spGSB/`。作成時にmetadata.json・model.jsonのHTTP 200を確認した。学校での取得・推論は未検証。

## 5：micro:bit More

拡張：micro:bit More。対応micro:bit、専用ファームウェア、Bluetooth接続が必要。

- 専用ファームウェア導入済みのmicro:bitを用意する。学校のBluetooth設定を確認する。
- micro:bit Moreの拡張パレットにある接続ボタンから機器を選んで接続し、緑の旗を押す。
- micro:bitのLEDに B2S が流れれば表示出力は合格。
- micro:bitのA/Bボタンを押すと画面の「ボタンA」「ボタンB」が変わり、傾けると「傾き」が変われば入力は合格。「明るさ」も確認できる。
- 接続していないときの0表示だけでは合格にならない。機器を持っていない場合は「未検証」と記録する。
